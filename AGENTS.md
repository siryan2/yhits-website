# AGENTS.md

This repo is **yhits-website** — the static website for [www.hit-services.net](http://www.hit-services.net/). Built with [Eleventy (v3)](https://www.11ty.dev/), templates are Nunjucks, styles are SCSS.

## Project structure

```
.
├── src/                # Eleventy input directory (templates, scss, js)
│   ├── _includes/      # Partial layouts / components
│   └── css/            # SCSS sources (compiled to /css/)
├── public/             # Static assets copied verbatim into dist/
├── eleventy.config.js  # Eleventy setup: plugins, image transforms, sass extension
├── biome.json          # Lint & format rules for src/**/*.js
└── package.json        # Scripts and dependencies
```

## Build / dev commands

```bash
npm run build     # npx @11ty/eleventy -> dist/ (output dir)
npm run dev       # npx @11ty/eleventy --serve  (live reload, port 8080 default)
npx @biomejs/biome check .   # lint + format src/**/*.js (single quotes, semicolons, 160 cols)
```

- `dist/` is the generated site. It is gitignored and deployed by CI (see below).
- There are no tests in this repo (`package.json` has no test script). The "test" is that `npm run build` succeeds and `dist/` looks correct.

## Code style guidelines

Formatting/linting follows [Biome 2.x](https://biomejs.dev/) via `biome.json`:
- Single quotes, semicolons always, trailing commas none (JS + JSON).
- Arrow function parens: `asNeeded`.
- Indent: 2 spaces, line width 160.
- Lint rules in `biome.json` are relaxed (`noExplicitAny`, `noForEach`, etc. turned off) — don't fight the config, keep it as-is unless a rule is genuinely useful.

## PR instructions

- Title format: `[<area>] <Title>` (e.g. `[templates] add Ludicamed project`).
- Target branch: **`develop`** — never push straight to `main`.
- Run `npm run build` before pushing; the deploy workflow (`deploy-prod.yml`) fails on a broken build.
- New content lives in `src/`, static images/assets in `public/`.

## Deployment

CI: `.github/workflows/deploy-prod.yml` runs on push to `main`:
1. `npm ci` + `npm run build` (Node 24)
2. SCP `dist/*` to the production server via SSH secrets (`HOST`, `PORT`, `SSH_USER`, `KEY`).

The deploy is a plain static-copy — no cache invalidation, CDN or DNS handling. Verify the site after every merge by checking https://www.hit-services.net/.

## Gotchas

- The `dist/` folder is generated; never commit it.
- Image optimization (`@11ty/eleventy-img`) writes webp/jpeg variants into `dist/img/` — handled automatically, no config change needed for new images.
- Sitemap is auto-generated by `@quasibit/eleventy-plugin-sitemap` (hostname: https://www.hit-services.net).
